# Enterprise Service Platform & Cyber-Hacker Control Terminal

A high-performance digital services, ads setup booking, template marketplace, and video course platform with an integrated Cyber-Hacker Owner Terminal.

## 🚀 Key Features

1. **Section #1: Digital Services**: Full-stack web, mobile app development, and IT consulting services.
2. **Section #2: Template Marketplace Vault**: Premium code templates accessible via a One-Time All-Access Purchase Package.
3. **Section #3: Ads Setup Booking (Direct - No Upfront Payment)**: Facebook, Google & TikTok ads campaign booking system. Submitting a booking instantly triggers a real-time notification in the Admin Terminal and displays a confirmation message to the customer (*"আপনার বুকিং সফল হয়েছে! আমাদের টিম খুব শীঘ্রই আপনার সাথে যোগাযোগ করবে।"*).
4. **Section #4: Video Course Engine**: Course player with Video #1 free preview (unlocked for all) and Video #2+ locked until purchase.
5. **Cyber-Hacker Owner Control Terminal (`/admin` / Secret Switcher)**:
   - Dark cyberpunk CRT aesthetic (`#050811`, neon green `#00ff8c`, cyan `#00e5ff`, scanlines).
   - Real-time audio-visual notifications for new bookings.
   - Section-by-section management: Ads Bookings, Template Vault, Course Video Locks, User Permissions.
6. **Strict No-Emoji Design**: 100% SVG vector iconography and dynamic glassmorphism.
